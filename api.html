KatMods API

Toda la información de los mods de Oliver en JSON: versiones, descargas, requisitos y la lista completa de bloques, ítems y entidades. Gratis y sin clave.

● Sin API key Solo GET CORS abierto JSON UTF-8
URL basehttps://kikerayo.github.io/KatMods/api

Endpoints

GET/index.json

Información de la API y la lista de endpoints.


    


    

      
GET/mods.json

      
Todos los mods del catálogo, con su resumen, icono y enlace de descarga.

      

    


    

      
GET/mods/.json

      
Detalle de un mod: descripción, requisitos, novedades, totales y el archivo .jar con su tamaño y sha256.

      

    


    

      
GET/mods//contenido.json

      
Todos los bloques, ítems y entidades del mod con su nombre en español (y su textura si está disponible). En los cheat menus incluye también la lista de modulos.

Ejemplo

    
Saber la última versión de Titans Mod desde JavaScript:


fetch("https://kikerayo.github.io/KatMods/api/mods/titanes.json")
  .then(r => r.json())
  .then(mod => console.log(mod.nombre, mod.version, mod.descarga));
